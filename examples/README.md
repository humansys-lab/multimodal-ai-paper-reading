## 文字列をトークンと数値で見る

入力は「京都の名物は」。指定モデルの分割は「京都」「の」「名」「物」「は」の5トークンでした。それぞれのIDと、入力埋め込みの先頭4要素を[実測JSON](open_weight_cpu_observation.json)に残しています。

- 1語・1文字・1トークンが常に一致するわけではありません。
- このモデルの入力埋め込みは1トークンにつき1,024要素です。先頭4つの数値だけから、その言葉の意味は判断できません。
- 続きの候補の確率は、語彙全体へsoftmaxを適用した値です。上位5候補だけを抜き出しているため、合計は1になりません。回答が事実として正しい確率でもありません。

JSONの`tokens`はトークナイザー内部の表記です。日本語で確認するときは`decoded_tokens`を見てください。内部表記をそのまま印刷して文字化けに見えることと、入力の日本語が失われたことを区別します。
