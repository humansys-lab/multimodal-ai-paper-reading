# 第1日 演習カード（配布前草稿）

全員でPaper2AgentのNature掲載版を読む。図1・2が必修、図3・4は補足。午後も同じ論文の図を使う。共通の版・指定範囲・基本3問は確定済みで、本編の根拠確認も完了している。資料のAI入力条件と授業経路の実機確認は別途必要。共通読解では論文を選ばない。共通3問は「主要な主張」「本文・図に対応する根拠」「不明点」。各演習の記録は[個人記録](../worksheets/reading_record.md)へ。通常の全体検討は15分の外で行う。

## 10:15–10:25：AIを使わずに読む

- **問い**：主張・根拠・不明点を自分の言葉で答えられるか
- **対象資料**：共通論文のAbstract（p1）とFig.1a/b・caption（p3）。終盤も同じ範囲
- **進め方**：AIなしで10分読む。3問に短く答える。分からないという記録も可。
- **記録**：朝のAIなしの説明（記録コードR0）。主張、本文・図の位置、不明点。
- **終わった人向け**：Fig.1の矢印とラベルを確認する。

次：10:25から最初のAI利用。

## 10:25–10:40：最初のAI利用

- **問い**：普段のAIとの対話で、共通論文の理解はどう補われるか
- **対象資料**：朝と同じ共通論文・共通3問
- **進め方**：5分：自分の質問で対話。5分：周囲と相談しAIと対話。5分：本人の説明を記録。
- **記録**：最初のAI利用後の説明（R1）。主要なやり取り、AIに任せたこと、本人の理解。
- **終わった人向け**：原論文のどこを確認したか印を付ける。

次：10:40から全体共有。

## 11:30–11:45：同じ資料で質問を変える

- **問い**：質問をどう変えると、図1について自分の説明を直せるか
- **対象資料**：共通論文の図1と最初のAI利用で残した入出力。まず同じ資料を使う
- **進め方**：5分：朝のAIなし・最初のAI利用の記録にある未解決点を一つ選び、質問の一部を変えて対話。5分：周囲と相談し、説明が理解に役立った箇所を確かめる。5分：新たに自分で説明できたことを記録。
- **記録**：元の質問・変更後の質問、入力と履歴の条件、AIの生回答、本人の説明の変化。朝の二つの記録は残す。
- **終わった人向け**：変化がない場合も、その条件と残る疑問を整理する。

次：11:45から講義。質問例は最初のAI利用後に[議論ガイド](../docs/figure12_dialogue.md)を参照。

## 12:05–12:20：図注・本文を追加する

- **問い**：図1の理解には、論文のどの情報まで必要か
- **対象資料**：共通論文の図1（p3）、図注、対応本文p2。共通の指定範囲と実際にAIへ送る範囲を区別する
- **進め方**：5分：図1の疑問を一つ選び、質問と現在の入力を確認して対話。5分：相談し、必要だと思う図注または本文を一つ追加して同じ問いを試す。5分：どの記述が自分の理解を助けたかを記録。
- **記録**：追加した位置、同じにした条件・変わった履歴、AIの説明と本人の説明、確認できた根拠。すでに十分なら無理に減らさない。
- **終わった人向け**：追加しても未解決なら、背景知識・外部資料が必要かを検討する。

次：12:20から図1の比較結果を共有。

## 13:30–13:45：図2の具体例を自分とAIで読む

- **問い**：図1の仕組みは、図2の具体例でどう使われ、何が評価されているか
- **対象資料**：共通論文の図2a〜dと図注（p4）、対応本文p3右段〜p5冒頭
- **進め方**：5分：冒頭に自分の説明を一文で残し、a/dの処理またはb/cの比較で分からない点をAIへ質問。5分：相談しながら図・本文と回答を照合。5分：自分が説明できるようになった点と不明点を記録。
- **記録**：AI利用前の一文、質問と実入力、AIの生回答、確認後の自分の説明、根拠位置。朝と終盤の比較記録とは別欄。
- **終わった人向け**：図1の構成要素と図2の具体例を対応付ける。

次：13:45から共有と図2の3問。

## 14:00–14:15：背景知識と外部根拠を尋ねる

- **問い**：図1・2の疑問のうち、背景知識や別の原資料が必要なのはどれか
- **対象資料**：共通論文の図1・2と対応本文。必要な用語・研究の背景を一つ選ぶ
- **進め方**：5分：共通論文で確認できる位置を探し、残る一つの疑問をAIに質問。5分：相談して、論文の記述・背景の説明・外部出典候補を区別。5分：分かったことと未確認の主張を記録。
- **記録**：質問、入力範囲、AIの回答、共通論文内の根拠、外部出典候補、検索実行の表示を確認できたか。不明は不明のまま。
- **終わった人向け**：出典候補のDOI・出版社ページを開いて確認。時間内に確認できなければ15:35からの根拠確認へ残す。

次：14:15から、背景の説明と外部根拠をどう確かめたか共有。

## 15:00–15:15：図2の入力範囲を見直す

- **問い**：図2の入力をどこまで含めると、残る疑問を説明できるか
- **対象資料**：図2と13:30の演習で残した入出力。画像・図注・対応本文の元位置を確認する
- **進め方**：5分：実入力と回答を見て、不足しそうな情報を一つ決める。5分：相談し、問いを保って入力を一つ追加・修正して対話。5分：AIの説明と自分の理解の変化を記録。
- **記録**：元ページ、追加・変更した範囲や形式、同じ条件・変わった履歴、根拠位置。全形式の比較はしない。
- **終わった人向け**：入力に情報があっても使われていない可能性を、原文との対応から考える。内部処理は断定しない。

次：15:15からPDF・確認方法の講義。

## 15:35–15:50：AIが補った説明の根拠を確かめる

- **問い**：AIが補った説明や挙げた出典は、原資料で裏付けられるか
- **対象資料**：図1・2、14:00の演習で残した未確認点。必要なら外部原著の該当箇所を一つ参照
- **進め方**：5分：未確認の主張を一つ選び、共通論文本文または外部の原資料を開く。5分：相談して該当箇所とAIの説明を照合し、必要なら問い直す。5分：採用・修正・保留と本人の理解を記録。
- **記録**：出典の実在確認、本文の読取り可否、主張を支える位置、検索／手動確認の経路。確認できない場合は理由を残す。
- **終わった人向け**：今回の条件でAIに任せられたことと、人間の確認が必要だったことを整理する。

次：15:50から休憩。別論文の通読や自動検索機能の実装は求めない。

## 16:00–16:15：朝と同じ範囲を読み直す

- **問い**：学んだことを踏まえ、共通3問をどう読み直すか
- **対象資料**：朝と同じ共通論文・同じ版・指定範囲・3問
- **進め方**：5分：新規会話で質問。5分：周囲と相談して対話。5分：本人の説明と変更理由を記録。
- **記録**：終盤の再読後の説明（R2）。原則新規、継続した場合は理由を明記。実入力の変更は可。午後の図を補足根拠にする場合は共通指定範囲外と明記。
- **終わった人向け**：変更しなかった点も理由を残す。

次：16:15から原文との照合。

## 16:15–16:30：原文と照合して説明を直す

- **問い**：直前の再読で作った説明を原論文と照合して、採用・修正・保留できるか
- **対象資料**：同じ共通論文の指定範囲・共通3問
- **進め方**：5分：主要な説明を原論文で確認。5分：相談しながら疑問をAIと検討。5分：判断と根拠を記録。
- **記録**：原文照合後の説明（R3の暫定版）。AI生回答と本人の修正文を別に残す。
- **終わった人向け**：条件や図の凡例をもう一度確認。

次：16:30から相互説明。

## 16:30–16:50：AI画面を閉じて説明し合う

- **問い**：AI画面を閉じても、主張と主要図を説明できるか
- **対象資料**：同じ共通論文の指定範囲・共通3問
- **進め方**：AI画面を閉じる。1人10分ずつ説明と質疑。原論文は参照可。
- **記録**：相互説明シートと相互説明後の記録。原文照合時点の記録は消さず別runまたは追記。
- **終わった人向け**：相手の質問から未解決点を整理。

次：16:50から全体振り返り。

## 17:30–18:00：相談・予備（任意参加）

本編は17:30まで。記録を保存し、希望者はHomeworkや接続・操作を相談する。この枠では新しい必修内容を扱わない。

## Notebook設定との対応（操作時に参照）

Notebookの`activity_id`には次のコードを使う。コードは記録を取り違えないためのもので、読む論文や問題を選ぶ欄ではない。

| 活動名 | 設定コード |
|---|---|
| AIを使わずに読む | `P0` |
| 最初のAI利用 | `P1` |
| 同じ資料で質問を変える | `L1` |
| 図注・本文を追加する | `L2` |
| 図2の具体例を自分とAIで読む | `V1` |
| 背景知識と外部根拠を尋ねる | `V2` |
| 図2の入力範囲を見直す | `V3` |
| AIが補った説明の根拠を確かめる | `V4` |
| 朝と同じ範囲を読み直す | `P2a` |
| 原文と照合して説明を直す | `P2b` |
| AI画面を閉じて説明し合う | `P3` |
