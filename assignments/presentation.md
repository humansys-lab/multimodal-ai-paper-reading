# 第2日：HW1の論文読解とHW2のAI活用を発表する

2026-10-31。**HW1・HW2はどちらも必須。スライドは2課題を合わせて10枚以下、1人15分です。** 受講者10名全員が発表します。10:10–11:25と11:35–12:50に各5名。発表順は別途案内します。

| 時間 | 内容 |
|---|---|
| 最初の5分 | HW1：選んだ論文の研究内容と、理解に至った過程 |
| 次の5分 | HW2：日常業務・学業・研究から選んだ用途でのAI活用 |
| 最後の5分 | 両課題への質疑・フィードバック |

## HW1で話す内容（5分）

1. 論文の出典と選定理由。何が便利・面白いと思ったか。
2. 理解するために行ったこと。最初の疑問、AIへの入力・問い、原資料の確認、説明を変えた理由。
3. どういう研究か。目的、新しい工夫、主要図1～2点、結果と限界を自分の言葉で説明する。
4. 読解手順の振り返り。何をAIに任せ、自分で何を確認し、何を保留したか。

聞き手が研究内容を追えるよう、読解過程の話が長くなりすぎないようにする。

論文の模式図、測定結果、AIの出力、本人の解釈を区別する。共通論文での結果と別論文での結果を比較して学習効果とは言わない。実装や著者実験の再現は必須にしない。

## HW2で話す内容（5分）

1. 選んだ用途と目的。どんな作業を助けたいか、何ができれば役立つか。
2. AIの使い方。渡した情報と主な質問、出力の具体例。
3. 自分による確認。どの資料・条件と照らし、何を採用・修正・保留したか。
4. 活用の判断。役立つ条件と限界、今後も自分で確認すること。

日常業務・学業・研究の3分野から一つ選ぶ。実施した内容と提案・未確認の内容を明示し、試せなかった場合は理由と確認方法を説明する。HW2にNature／Scienceの論文選定条件は適用しない。

## スライドと質疑

8枚の構成例：HW1の出典・動機／研究の目的・方法／主要図と結果／理解の過程と確認、HW2の用途・目的／入力と出力／自分による確認／活用の判断。枚数配分は固定せず、表紙・参考文献を含めて合計10枚以下に収める。

聞き手は両課題について「分かった内容」「参考にしたい方法」「確認したい根拠」を短く記録する。本人の理解・根拠・不明点・変更理由を見てPass/Not passを判断し、自動採点しない。AIの出力が正しかったかだけで評価しない。
