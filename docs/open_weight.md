# 公開重みの小型モデルで仕組みを観察する

`notebooks/03_open_weight_lab.ipynb`は、LLMの説明を手元で確かめる補助教材です。初回の共通読解後に使います。共通論文・指定範囲・3問・5＋5＋5は変えません。

## 観察すること

1. 「京都の名物は」を実際のトークンに分け、IDと入力埋め込みを確認する。
2. 「名物」を「観光名所」に変え、次のトークン候補が変わるかを見る。候補には句読点も含まれる。
3. 自分の質問で短い応答を作り、説明できたことと不明点を保存する。

[Qwen3-0.6Bの公開元](https://huggingface.co/Qwen/Qwen3-0.6B)はApache 2.0で重みを公開しています。教材ではrevision `c1899de289a04d12100db370d81485cdf75e47ca`を固定します。モデル名だけから他のLLMの性質を一般化しません。`trust_remote_code=False`、safetensorsを使用し、思考モードを明示的に無効化します。

## 計算機

- **Colab**：T4 GPU（16 GB）に確定（ユーザーのYES）。CUDA・float16、入力512/出力128トークン以下。重みは約1.2 GBですが、実際には作業メモリも必要です。**Colab実機での成功・ピーク使用量は未確認**。
- **このMac**：Apple M3 Max、メモリ64 GB。PyTorchのMPSを明示的に選択し、float16で実行成功。読み込み約12.2秒。短い日本語2件は約12.1秒（96トークン上限で中断）と約4.5秒（完了）。実行後のMPS確保量は約1.19 GB、ドライバ確保量は約1.28 GB。ピーク値ではありません。
- **CPU**：明示的に選べますが今回未実測。GPUの失敗時に自動で選びません。

[Colab公式FAQ](https://research.google.com/colaboratory/faq.html)では、割当て機種や利用可能量は変動すると説明されています。10人が同時に同じGPUを使える保証にはしません。個人PCへのGPU導入は不要です。

## 実行と保存

教材一式を展開して03を開きます。必要なときだけ依存のインストールとモデル取得を有効にします。質問は空欄から始め、会話テンプレートを画面で確認してから実行します。毎回新規会話で、非公開資料・個人情報は使いません。

依存は別の `requirements-open-weight.txt`。既存00〜02の環境に大型ライブラリを必須追加しません。Colabで依存を変更した際に再起動が必要なら、保存後にランタイムを再起動します。

API送信はなく、モデル取得後の推論はその計算機上で行います。ローカル実行によるAPI料金は0 USDですが、Colabの利用枠や電力は別です。結果は `outputs/open-weight/<run_id>.json` に保存し、共通論文の朝・講義後の記録と分けます。

このMacの移動中の確認には、[オフライン確認セット](offline_review.md)を使えます。セット内のキャッシュから読込み・生成・保存を実行済みです。03用カーネルと `DEVICE="mps"` を選び、インストールとダウンロードは無効のまま使ってください。

小型モデルには不十分・誤った説明や出力途中の終了がありました。動いたことと、説明が正しいことを分けて評価してください。
