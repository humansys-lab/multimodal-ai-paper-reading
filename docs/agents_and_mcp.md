# エージェントとMCPを図1から理解する

授業での利用：P1の記録後、11:45以降の補助説明。第1日の追加読解論文ではない。

- **LLM**：入力された文章や資料などに応じて出力を生成するモデル。
- **エージェント**：モデルの判断を道具の操作へつなぎ、結果を受けて次の行動を選ぶ仕組み。人間が目的や権限を決め、結果の根拠を確認する。
- **MCP（Model Context Protocol）**：AIアプリと、資料や道具を提供するプログラムがやり取りするための共通の約束。モデルそのものでも、正解を保証する仕組みでもない。
- **tools**：入力を受け取って処理を実行する道具。**resources**：参照する資料やデータ。**prompts**：再利用できる指示や手順のひな型。

図1aでは何を利用できるか、図1bではそれをどう用意して検査するかを追う。構築段階でのテストと、利用段階での質問への回答を区別する。MCPの接続方法だけで、テスト内容・元データ・研究の結論が正しいとは決まらない。

図2dの計画・行動・観察は、道具を使う流れを説明する例。論文に示された説明を、モデルの非公開思考を完全に観測した記録だと解釈しない。

問い：論文PDFをGUIへ添付する操作と、論文のコードを呼び出す操作では、何が異なるか。図のどこにその違いが表れているか。
