[GitHubの教材入口](https://github.com/humansys-lab/multimodal-ai-paper-reading)の「Colabで開く」から起動できます。手元の`.ipynb`を使う場合は、[Google Colab](https://colab.research.google.com/)の「ノートブックを開く」→「アップロード」で選びます。

### 最初の準備

1. **00・01・02はCPU、03はT4 GPU**を選ぶ（「ランタイム」→「ランタイムのタイプを変更」）。T4が割り当たらなければ教員・TAへ伝える。
2. 00はインストール不要。01・02は冒頭、03はモデル準備の既存セルで`INSTALL = True`にし、実行する。その後、折りたたまれた関数定義セルも上から実行する。
3. 01・02では、教員から**別途個別に受け取る**`connection.local.yaml`をColab左のファイル欄へアップロード。「パスをコピー」し、`connection_path = '/content/connection.local.yaml'`のように記入して実行する。モデル・接続経路の表示を確認する。
4. **APIキーは送信時の伏字入力欄だけ**に入れる。接続ファイル・コード・質問文・提出物には書かない。公開の`connection.example.yaml`は空の見本で、接続には使えない。

接続設定と個別キーは共通ZIPに含みません。未受領なら教員・TAへ確認してください。01と02の新しいランタイムには、各々へ設定・入力資料をアップロードします。画面上の「設定の読込み完了」は、API疎通成功とは別です。

**スライド3の準備名の読み替え**：`PREPARE_COLAB = True`は旧版の名前です。今回の配布版は上記の`INSTALL = True`を使います。変数を新しく追加する必要はありません。

## 2. 演習ごとの操作

### 朝：まず自分の説明を残す（スライド4）

Paper2Agentの**要旨p1 → 図1a・bと図注p3 → p2右段の指定本文**を読みます。指定本文は「We implemented Paper2Agent...」から「...across multiple papers simultaneously.」までの1段落。朝も再読もこの範囲・同じ3問です。

00の`record_stage = '朝：AIなしで読む'`を実行し、主張・根拠・不明点を自分の言葉で記入します。`SAVE = True`で保存。相互説明後は`'午後：説明し直す'`へ切り替えて別の説明を残します。

### AIを使う：02の活動と入力を切り替える

表の資料を`materials/`からColabへアップロードし、実際のパスを`local_path`へコピーします。PDFページは**原論文PDFの先頭を1として数えます**。スライドのページではありません。

| 場面／スライド | `activity_id` | 入力ファイル | `input_kind`／`pdf_pages` |
|---|---|---|---|
| 初読／5 | `'P1'` | `Paper2Agent_Nature.pdf` | `'pdf'`／`[1, 2, 3]` |
| 質問の比較／24 | `'L2'` | 同じPDF | `'pdf'`／`[2, 3]` |
| 図2／32–33 | `'V1'` | `fig2_full.png` | `'image'` |
| 画像比較／46–47 | `'V2'` | `fig2_full.png` → `fig2_quarter.png` | 両方`'image'` |
| 再読／51 | `'P2a'` | `Paper2Agent_Nature.pdf` | `'pdf'`／`[1, 2, 3]` |
| 別論文／55–56 | `'TRANSFER'` | `ai_scientist_nature.pdf` | `'pdf'`／`[1, 2, 3, 4, 5]` |

**毎回の順番**：質問を`question`へ → 入力セルを`PREPARE_INPUT = True`で実行 → プレビュー → 送信内容を確認して`SEND = True` → 原文と照合 → 自分の説明を書き`SAVE = True`。

- 比較は`conversation_mode = 'new'`。Aを保存してから`START_NEXT_RUN = True`、Bの質問・入力準備・プレビューを再実行する。活動を変えるときは接続設定セルの`activity_id`も変更・実行する。
- PDFの送信対象はページ全体で、指定した読解範囲より広い。図2はp4全体の画像。`source_location`に原論文・ページ・図を記入する。
- 画像比較は**1600×2126 → 400×532画素**。質問・モデル・新規会話はそろえ、ファイルだけを替える。表示画像と画素数を確認する。

### モデルの観察とMethods

**03／スライド20**：初回`ALLOW_DOWNLOAD = True`、`DEVICE = 'cuda'`、`LOAD_MODEL = True`。`TEXT`を記入して`OBSERVE = True`にし、トークン→埋め込み→候補確率のセルを順に実行します。この版は1回に1文です。`京都の名物は`と`京都の観光名所は`を、`TEXT`を書き換えて順に比べます。入力・トークン数・上位候補・気付きを手元へ記録。生成まで試した場合は`SAVE`でJSON保存できます。

**01／スライド52**：`activity_id = 'METHODS'`。p10–12の指定された問いを選び、必要な原文を`source_excerpt`、ページ・節を`source_location`へ記入。質問→プレビュー→送信→保存。朝の3問とは別の記録になります。

## 3. 保存・提出・困ったとき

### 閉じる前に保存する

1. `annotations`の本人の説明・根拠・不明点を記入し、`SAVE = True`で保存セルを実行する。
2. `保存:`に出たファイルをColabのファイル欄からダウンロードする。00・01・02は`.md`と`.jsonl`、03の通常生成は`.json`。Notebook本体の保存とは別。
3. 朝の説明、AIの生回答、自分の修正文を区別して残す。別論文の結果で朝の記録を上書きしない。

**本人の説明**＝何を理解したか／**根拠**＝論文・PDFページ・図・段落／**不明点**＝まだ説明できないこと。変更した場合は、その理由も短く残します。Colabのランタイムが削除されると、そこに置いたファイルは消えます。

| 困ったこと | 最初に確かめること |
|---|---|
| ファイルが見つからない | 実行中のColabへアップロードしたか。PCのDownloadsのパスは使えない。ファイル欄から実際のパスをコピーする |
| 接続設定・キーがない／設定エラー | 教員・TAへ確認。空見本や検査欄を書き換えて進めない |
| 入力条件が未確認、認証・予算・通信エラー | 送信を止め、表示された種類を教員・TAへ伝える。キーや接続先を画面写真に含めない。自動再送はしない |
| 条件を変えたのに反映されない | 値を変更したセルを実行し、入力準備・プレビューをやり直す |
| 同じ番号で再送できない | 前の結果を保存して「次の実行番号」。タイムアウト時は課金不明なので、先に相談する |
