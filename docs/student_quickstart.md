## 1. 最初に開くもの

配布ZIPを展開し、`day1_student_script_aligned.pdf`と、この手順書を開きます。Notebookは**使う1冊だけ**Colabで開き、上からセルを実行します。PCにPythonを入れる必要はありません。

| ファイル | 役割 |
|---|---|
| `day1_student_script_aligned.pdf` | 最終スライド。以下のスライド番号は右上の番号（表紙は0） |
| `00_setup.ipynb` | 朝の自分の説明と、相互説明後の説明を保存 |
| `02_document_lab.ipynb` | 朝のAI読解、質問比較、画像比較、再読、The AI Scientist |
| `03_open_weight_lab.ipynb` | 文章・トークン・候補確率を観察 |
| `01_dialogue_lab.ipynb` | Methodsの必要な段落を貼り付けて対話 |
| `materials/` | 同じ版の原論文PDF 2報と、図2の比較画像2枚 |

[GitHubの教材入口](https://github.com/humansys-lab/multimodal-ai-paper-reading)の「Colabで開く」から起動できます。手元の`.ipynb`を使う場合は、[Google Colab](https://colab.research.google.com/)の「ノートブックを開く」→「アップロード」で選びます。

### 最初の準備

1. **00・01・02はCPU、03はT4 GPU**を選ぶ（「ランタイム」→「ランタイムのタイプを変更」）。T4が割り当たらなければ教員・TAへ伝える。
2. 00はインストール不要。01・02は1aのINSTALLをチェックして実行し、1bの関数準備も実行する。03はモデル準備で`INSTALL = True`にして実行する。**03は導入後に必ずランタイムを再起動し、`INSTALL = False`へ戻す。** 保存先・折りたたまれた関数定義セルも上から再実行してから「2」へ進む。
3. 01・02の2でUPLOAD_CONNECTIONをチェックし、▶で**別途個別に受け取る**`connection.local.yaml`を選ぶ。次回はチェックを外せば同じファイルを使える。モデル・活動は選択欄で指定する。
4. **APIキーは送信時の伏字入力欄だけ**に入れる。接続ファイル・コード・質問文・提出物には書かない。公開の`connection.example.yaml`は空の見本で、接続には使えない。

接続設定と個別キーは共通ZIPに含みません。未受領なら教員・TAへ確認してください。01と02の新しいランタイムには、各々へ設定・入力資料をアップロードします。画面上の「設定の読込み完了」は、API疎通成功とは別です。

**スライド3の準備名の読み替え**：`PREPARE_COLAB = True`は旧版の名前です。今回の配布版は上記の`INSTALL = True`を使います。変数を新しく追加する必要はありません。

## 2. 演習ごとの操作

### 朝：まず自分の説明を残す（スライド4）

Paper2Agentの**要旨p1 → 図1a・bと図注p3 → p2右段の指定本文**を読みます。指定本文は「We implemented Paper2Agent...」から「...across multiple papers simultaneously.」までの1段落。朝も再読もこの範囲・同じ3問です。

00の`record_stage = '朝：AIなしで読む'`を実行し、主張・根拠・不明点を自分の言葉で記入します。`SAVE = True`で保存。相互説明後は`'午後：説明し直す'`へ切り替えて別の説明を残します。

### AIを使う：02の活動と入力を切り替える

02の3でPREPARE_INPUTをチェックして▶を押し、表の資料をPCの`materials/`から選びます。PDFページは**原論文PDFの先頭を1として数えます**。スライドのページではありません。

| 場面／スライド | 活動 | 入力ファイル | 種類／ページ |
|---|---|---|---|
| 初読／5 | 朝のAI読解 | `Paper2Agent_Nature.pdf` | PDF／1-3 |
| 質問の比較／24 | 質問を比べる | 同じPDF | PDF／2-3 |
| 図2／32–33 | 図2を読む | `fig2_full.png` | 画像 |
| 画像比較／46–47 | 画像の大きさを比べる | `fig2_full.png` → `fig2_quarter.png` | 両方画像 |
| 再読／51 | 同じ3問に答え直す | `Paper2Agent_Nature.pdf` | PDF／1-3 |
| 別論文／55–56 | The AI Scientistを読む | `ai_scientist_nature.pdf` | PDF／1-5 |

**毎回の順番**：3で入力を選ぶ → 4aに質問を書いて実行し、4bで送信内容を確認 → 5のSENDで送信 → 原文と照合 → 6に自分の説明を書き、SAVE・DOWNLOADをチェックして保存。

- 比較は「新しく始める」。Aを保存したら、Bの入力と質問を用意して同じ順に実行する。活動・モデルを変える場合は2も実行する。
- PDFの送信対象はページ全体で、指定した読解範囲より広い。図2はp4全体の画像。`source_location`に原論文・ページ・図を記入する。
- 画像比較は**1600×2126 → 400×532画素**。質問・モデル・新規会話はそろえ、ファイルだけを替える。表示画像と画素数を確認する。

### モデルの観察とMethods

**03／スライド20**：初回`ALLOW_DOWNLOAD = True`、`DEVICE = 'cuda'`、`LOAD_MODEL = True`。`TEXT`を記入して`OBSERVE = True`にし、トークン→埋め込み→候補確率のセルを順に実行します。この版は1回に1文です。`京都の名物は`と`京都の観光名所は`を、`TEXT`を書き換えて順に比べます。入力・トークン数・上位候補・気付きを手元へ記録。生成まで試した場合は`SAVE`でJSON保存できます。

**01／スライド52**：2で「Methodsを読む」を選ぶ。3aに問い・必要な原文・ページや節を記入して実行し、3bで送信内容を確認。4で送信し、5で保存する。朝の3問とは別の記録になります。

## 3. 保存・提出・困ったとき

### 閉じる前に保存する

1. 本人の説明・根拠・不明点を記入する。01・02はSAVEとDOWNLOADをチェックして▶。00・03は`SAVE = True`で保存する。
2. 01・02はZIPがPCに届いたことを確認する。00は`.md`と`.jsonl`、03は`.json`をColabのファイル欄からダウンロード。Notebook本体の保存とは別。
3. 朝の説明、AIの生回答、自分の修正文を区別して残す。別論文の結果で朝の記録を上書きしない。

**本人の説明**＝何を理解したか／**根拠**＝論文・PDFページ・図・段落／**不明点**＝まだ説明できないこと。変更した場合は、その理由も短く残します。Colabのランタイムが削除されると、そこに置いたファイルは消えます。

| 困ったこと | 最初に確かめること |
|---|---|
| ファイルが見つからない | 2の接続ファイル、02の3の入力資料を選び直す。選択は1ファイルずつ |
| 接続設定・キーがない／設定エラー | 教員・TAへ確認。空見本や検査欄を書き換えて進めない |
| 入力条件が未確認、認証・予算・通信エラー | 送信を止め、表示された種類を教員・TAへ伝える。キーや接続先を画面写真に含めない。自動再送はしない |
| 条件を変えたのに反映されない | 変更したセルを実行し、質問セルで送信内容を確認し直す |
| 同じ番号で再送できない | 前の結果を保存して質問セルから実行する。タイムアウト時は課金不明なので先に相談 |
