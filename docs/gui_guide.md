# Gemini for Educationで読む・保存する（実アカウント確認待ち）

共通GUIは大学のGemini for Education。画面名や添付上限は大学アカウントで未検証。教員が案内する大学アカウントで利用可否を確認し、個人の有料契約へ自動的に切り替えない。

## 演習前

1. [個人記録](../worksheets/reading_record.md)を自分の手元へコピー。Markdown記法を覚える必要はなく、テキストとして書ける。
2. 教員が固定したP01の版・指定範囲を確認。共通課題では論文を選ばない。P0の10分はAIを開かず読む。
3. P1では空の質問欄から自分で質問。資料のAI入力可否を教員の素材ガイドで確認し、添付した範囲を記録。未公開研究・個人情報は入れない。

第1日の午後も同じPaper2Agent掲載版を開く。V1/V3は図2（p4）、V2/V4は図1・2の背景と外部根拠を扱う。図3・4は補足。朝と終盤の共通読解はAbstract p1＋Fig.1a/b・caption p3に確定し、全員が同じ版と範囲を読む。実際にAIへ送った範囲と、読むよう指定された範囲は別に記録する。

## 5＋5＋5

- 最初の5分：自分で考えてAIに質問。AIへ渡したページ・図・抜粋と、質問を記録する。
- 次の5分：周囲と相談しながら対話。「どこを原資料で確認したか」を互いに指す。
- 最後の5分：本人の説明・根拠・不明点・変更理由を短く残す。主要な質問と回答は別にそのまま保存。

## 背景知識・外部出典の確認

論文の記述とAIが補った説明を分ける。検索実行の表示を確認できなければ、検索したと断定しない。出典候補は本人がDOI・出版社で実在と該当本文を確かめる。手動確認した場合は経路を記録する。詳しくは[図1・2の議論ガイド](figure12_dialogue.md)。

## 新規・継続・保存

P2a（R2）は新しい会話から始めるのが原則。入力準備や自分の記録は使える。継続した場合はその条件と理由を書く。P2bは回答を原文と照合、P3はAI画面を閉じて相互説明。

主要な質問・回答をコピーしてローカルのテキストへ保存する。AI原文を直す場合は別の「本人の修正文」欄へ。公開共有リンクは不要。モデル名は画面で分かる範囲のみ記入し、不明な内部版・token数・費用はnull/不明。

保存後にファイルを開き、日本語・図番号・修正文が残ったことを確認する。個人の対話ログ原本は手元へ保存し、発表スライド・最終レポートはPDFにして参加済みの指定Slackチャンネルへ提出する。レポートの別添には説明に必要なログをまとめる。障害時は自動で別サービスに替えず教員へ相談。教員が経路変更を指示した場合は変更前後のサービスを記録する。

## Homeworkでの記録

HW1・HW2はどちらも必須。HW1は[読解記録](../worksheets/reading_record.md)、HW2は[活用記録](../worksheets/application_record.md)へ別々に保存する。HW2では日常業務・学業・研究から身近な用途を一つ選び、空の質問欄から自分で問いを作る。資料や生出力、自分で確認したことを残し、第2日に各5分で発表する。課題の詳細は[Homework要項](../assignments/homework.md)。

HW2記録は手元のMarkdown／テキストで作成できる。現在のnotebookの論文選択欄はHW1用。HW2を記録するために架空の論文・DOIを入力する必要はない。

[Google公式案内](https://edu.google.com/ai/gemini-for-education/)は一般説明。大学アカウントでの添付・保存・利用枠の実機試験を代替しない。
