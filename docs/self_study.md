# 自習の進め方

公開リポジトリの素材ガイド・空の記録様式・Notebookは、大学アカウントやSlackなしでも閲覧できます。APIを実行する環境の確認は別に必要です。

1. 採用済みの共通論文ガイドが配布されたら、指定範囲をAIなしで読み、3問を記録する。
2. 利用できるGUIで同じ範囲について対話し、原資料で確かめる。直接APIを使う場合は自分の認証・費用と入力権利の確認が必要。
3. AIを閉じて説明を書き直す。Notebook 03を試した後は、[公開重みモデルの実測例](../examples/README.md)で、トークンの観察と、回答が指定の形式を守らなかった例を比較できる。

論文を読んだ教員の検証済み対話例は未作成。公開した小型モデルの観察例を、論文読解やColab T4の成功例として扱わない。試験用の人工応答は自習の実測例に流用しない。自分で確認できない説明は保留し、根拠の所在を示す。無料で全APIを実行できるとは限らない。
