# 検査の範囲

ローカルでAPI不要158件、教材構造、Notebook 4冊の既定セルの検査を行い、GitHub Actionsでも同じ検査を実行します。実行結果はPRのChecksで確認できます。

直接OpenAI APIの文字・対話・画像は動作確認済みです。PDFは人工図の条件によって成功と失敗があり、授業用経路の保証には使いません。公開重みモデルはMacのMPSとCPUで明示的に機種を選んで実行しました。ColabのT4、大学Gemini、講義用中継、予算停止、同時アクセスは未検証です。

公開runtimeは空の例です。検証した個別設定がなければAPI送信はエラーで停止します。既定のNotebookは送信・モデル取得・推論を実行しません。
