# Notebookの操作

[当日の手順書](student_quickstart.md)から、使うNotebookを1冊だけ開きます。00〜02はCPU、03はT4 GPUです。01・02は選択欄を使い、変更後にセル左の▶を押します。

## 01・02：初回の準備

1. **1a**：INSTALLをチェックして▶。完了後はチェックを外す。
2. **1b**：▶で関数を準備する。授業中にここを書き換える必要はない。必要な関数はすべてNotebook内にあり、「コードを表示」で読める。
3. **2**：UPLOAD_CONNECTIONをチェックして▶。教員から個別に受け取った`connection.local.yaml`を1つ選ぶ。次からはチェックを外せば同じファイルを使う。モデル・活動はドロップダウンで選ぶ。

キーは送信時の伏字欄だけに入力します。接続ファイルとキーは共通ZIP・GitHubにはありません。公開の空見本を改名しても使えません。未受領なら教員・TAへ確認してください。Notebookを切り替えたり、新しいランタイムにしたりした場合は準備をやり直します。

## 質問するたびに行うこと

| 操作 | 01：文章 | 02：画像・PDF |
|---|---|---|
| 入力を準備 | 3で文章と元のページ・節を記入 | 3でファイルを選び、種類とPDFページを指定 |
| 質問と確認 | 3a→3bを実行 | 4a→4bを実行 |
| APIに送る | 4のSENDをチェックして実行 | 5のSENDをチェックして実行 |
| 自分の説明を保存 | 5の記入欄とSAVE・DOWNLOAD | 6の記入欄とSAVE・DOWNLOAD |

01の3a／02の4aでは、三重引用符の間に質問・原文を記入して実行します。続く3b／4bで会話の条件を選び、▶を押すと質問・添付・送る会話の全文が表示されます。内容を確認してから送信してください。**料金がかかるのは送信の操作だけ**です。回答を論文で確かめ、自分の説明を別欄へ記入します。

「新しく始める」は過去の会話を送りません。「前の会話を続ける」は過去の質問と回答も送ります。比較実験やモデル変更では「新しく始める」を選んでください。過去の記録はどちらでも残ります。

保存後は質問セルへ戻るだけで次の質問ができます。実行番号を自分で更新する操作はなくなりました。送信セルだけを繰り返すと、二重送信を避けるため停止します。フォームを変更しただけでは計算に反映されないので、そのセルも実行してください。

### 02のファイル選択

- 初回・別ファイル：3で「ファイルを選ぶ」を選び、PREPARE_INPUTをチェックして▶。PCから1ファイルを選ぶ。パスのコピーは不要。
- 同じファイルの別ページ：「前と同じファイル」を選び、ページを変えて▶。
- PDFページは先頭を1として`1-3`や`1,3`と記入。選択したページ全体を送る。
- 画像は元の論文・ページ・図を記入。送信する画像と画素数を確認する。「画像を縮小」だけwidth欄を使う。

ファイル選択をキャンセルしたときや準備に失敗したときは停止し、古い入力を送りません。元ファイルと違う入力形式への自動切替はしません。

### 保存

SAVEとDOWNLOADをチェックして▶を押すと、読みやすいMarkdownと再利用用JSONLをZIPでダウンロードします。PCにZIPが届いたことを確認してください。ダウンロードだけが失敗した場合は、Colabのファイル欄の`outputs/`から保存済みのZIPまたは2ファイルを取り出せます。

空の記入欄は前の記入を保持します。質問を変えたときは、フォームに残るメモも見直してください。生のAI回答を上書きせず、自分の説明と分けて記録します。ランタイムを閉じる前に必ずPCへ保存してください。Notebook本体の保存とは別です。

## モデルと回答の長さ

選べるのは`gpt-6-luna`、`gpt-6-sol`、`gpt-4.1-mini`です。モデルを変えるときは2を実行し、質問を「新しく始める」にします。通常はLunaを使います。接続設定を読み込めたことと、APIで成功したことは別です。[対応機能・実測状況](capability_audit.md)を参照してください。

`max_output_tokens`は推論と回答を合わせた出力の上限です。初期値は2048。`incomplete`で途中までしか出ない場合は、表示された理由を確かめ、上限を増やすか質問を絞って質問セルから再実行します。技術的に使えない設定はエラーで示します。

### 発展：設定を変えて比べる

01の3b／02の4bの「コードを表示」を押すと`parameters`を編集できます。初期設定はLunaが`reasoning={'effort':'none'}`、Solが`reasoning={'effort':'low'}`。GPT-4.1 miniにはreasoningを付けません。

- **temperature**：出力のばらつきを調整する設定。GPT-4.1 miniでは、例として`parameters['temperature'] = 0.7`を追加できます。
- **top_p**：候補の累積確率に関する設定。GPT-4.1 miniでは、別の実験として`parameters['top_p'] = 0.9`を追加できます。
- Luna・Solでtemperature/top_pを使う場合はreasoningをnoneにします。low等との併用はエラーです。一度に変える条件は1つにします。

古いモデルにも利用できる生成設定があります。モデルごとの公式資料は[対応機能の一覧](capability_audit.md)、用語は[用語集](glossary.md#notebookの生成設定を読む)を参照してください。利用額・回数の上限は教員がAPI側で管理します。

## Homework・自分のPCで使う場合

Homeworkでは末尾の補足セルを開き、書誌・対象誌・利用条件を記入してから切り替えます。[課題要項](../assignments/homework.md)の条件を満たす別論文を選びます。共通論文の初読・再読は固定の資料・範囲・3問です。

Colab以外でも関数とコードは同じです。接続セルのコードを開いて`connection_path`に既存ファイルを指定します。02では「パスを指定する（PCで実行）」を選び、コードの`local_path`を記入します。保存時はDOWNLOADを外してください。別の入力形式や実行環境へ自動で切り替える機能はありません。

## 00：朝と相互説明後の記録

朝は`record_stage='朝：AIなしで読む'`。共通の論文・版・範囲・3問を確認し、`annotations`へ自分の説明・根拠・不明点を記入します。`None`は前の記入を保持。`SAVE=True`でJSONLとMarkdownを保存します。APIは呼びません。

15:40の相互説明後は`'午後：説明し直す'`へ変更して範囲の確認セルを実行し、説明を記入して保存します。朝と午後は別々の記録で、同じファイルへ保存できます。朝の記録は保存直後にダウンロードしてください。ランタイムが再起動した場合、午後のファイルと手元の朝のファイルを並べて見比べます。

## 03：中の計算を観察する

1. `INSTALL=True`でtorch 2.8.0・torchvision 0.23.0・Transformers 4.57.6を一度導入し、**必ずランタイムを再起動**。`INSTALL=False`に戻し、冒頭の保存先・関数定義セルを再実行してから「2」へ進む。`DEVICE='cuda'`はColab、`'mps'`はMac。初回取得は`ALLOW_DOWNLOAD=True`。`LOAD_MODEL=True`で、確認済みのライブラリ版を検査してから読み込む。機種や版が合わなければ停止する。
2. `OBSERVE=True`で、トークン→埋込み→softmaxによる次の候補確率を順に見る。計算コードは各セルにある。
3. 生成設定の`temperature`・`top_k`・`top_p`・`seed`は固定。意味は[用語集](glossary.md#notebookの生成設定を読む)で確認できる。`PROMPT`へ自分の問いを書き、`PREVIEW=True`で会話テンプレートを確認。`RUN=True`で生成する。問いを変えたら再プレビューする。
4. 本人の説明を`annotations`に記入し、`SAVE=True`で生回答と一緒にJSONへ保存する。保存OFFでは書き換わらず、同じ実行のファイルは上書きしない。

`output_limit`は出力上限で止まった途中の回答です。入力は2,048、出力は128トークン以下。失敗時に以前の回答を今回の結果として保存できません。

論文の読解記録も必要なら、**生成前に**`activity_id`を指定します。`SAVE=True`で、生のJSONに加えてJSONLとMarkdownも一度に保存します。生成時の活動・資料・入力位置を保存し、後から違う活動へ付け替えません。観察だけなら`activity_id=None`で構いません。

## 困ったとき

| 状況 | 対処 |
|---|---|
| 選択をキャンセルした／違うファイルを選んだ | そのセルをもう一度実行し、1ファイルだけ選ぶ |
| 変更が反映されない | 変更したセルと質問セルを実行して、送信前の表示を確認 |
| 同じ質問をもう一度送りたい | 先に保存し、質問セルから実行し直す |
| 認証・予算・通信のエラー | エラーの種類を教員・TAへ。キーや接続先は画面写真に含めない |
| タイムアウト／中断 | 費用は不明。自動では再送しないので教員・TAへ相談 |
| 以前の許可IDや素材確認エラーが出る | 記録を保存して、READMEの最新版を新しいランタイムで開く |

このNotebookはWeb検索をしません。AIの出典は自分で出版社・本文を確かめます。質問方法と原著論文は[講義の参考文献](lecture_references.md)へ。

## 採用したColab機能と確認範囲

[Colab公式Forms](https://colab.research.google.com/notebooks/forms.ipynb)にあるドロップダウン、チェックボックス、短い文字・整数の入力欄、コードの折りたたみを使います。ラジオボタン相当の選択には標準のドロップダウンを採用し、画面用ライブラリを追加しません。変更時の自動実行は使いません。複数行の文字を標準フォームへ貼ると改行が除去されることをブラウザで確認したため、質問・原文にはColabのコード編集欄を使い、改行を保持します。保存時の短いメモは1行のフォームです。

ファイル選択とダウンロードは、[Google公式colabtoolsのfiles.py](https://github.com/googlecolab/colabtools/blob/main/google/colab/files.py)の`files.upload(target_dir=...)`と`files.download(...)`を使います。アップロードで実際に保存された名前を使うため、同名ファイルに連番が付いても手でパスを直す必要はありません。
