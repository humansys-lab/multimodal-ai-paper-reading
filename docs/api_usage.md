# 講義用APIの利用案内（配布前草稿）

講義用APIは、教員から接続案内を受け取ってから、**2026年11月14日23:59（日本時間）まで**利用できます。

## 利用量と費用

講義で紹介する基本的な使い方を想定し、**講義期間全体で1人10 USD分の予算を確保しています**。基本的な利用は、この予算内で進められる想定です。安心して試してください。

**学生全体の合計使用量には上限があります。** 長い資料の大量送信や自動的な連続実行をする前に、教員へ相談してください。利用枠が定期的に補充されることはありません。上限の案内が出たら送信を止め、教員へ確認してください。

## APIキー・接続情報の扱い

APIキーは、講義用APIを利用するための秘密情報です。教員が案内する専用の入力欄で扱ってください。

- 配布されたAPIキー・接続情報を、Webサイト、GitHub、Slackの投稿、他のAIサービスなどへアップロードしないでください。
- notebook本文や出力、スクリーンショット、発表・提出PDFにも含めず、他の人へ渡さないでください。
- 誤って載せた場合は使用を止め、キー自体を書かずに教員へ連絡してください。

課題のPDFは、これまでの案内どおり指定Slackチャンネルへ提出します。アップロード前に、APIキー・接続情報が含まれていないことを確認してください。

接続や操作で困ったらTAへ、利用枠については教員へ相談してください。[困ったとき](troubleshooting.md)も参照できます。
