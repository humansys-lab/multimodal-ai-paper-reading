# 講義用Notebookの確認記録（2026-10-02）

## 変更点

- 00はPyYAMLだけ、01はPyYAML＋OpenAI SDK、02は画像・PDF用を追加する用途別の固定依存に分離。03にはモデル用のPyTorch＋Transformersを導入する。
- 01・02は接続準備と繰り返し使う質問欄を分離。送信許可の設定例をNotebook内に置いた。
- 02は元画像／縮小画像／PDFを一か所で選ぶ。準備失敗時に以前の入力を残さない。
- プレビュー後の条件変更、別の実行への説明の誤保存、失敗後の古い生成結果の保存を拒否。本人の説明を保存セルの再実行で消さない。
- 03のトークン分割・埋込み・候補確率の計算はセルに表示。生成時点の活動と入力位置を固定して記録する。

### 正常実行と回答の正しさ

Macの短文生成は0.214秒、正常終了`completed`。パラメータ数596,049,920。首都を尋ねた回答は「京都」で誤りだった。生回答を保持し、正答に置き換えていない。論文の理解度・精度はこの試験では評価していない。

### API費用と仕様の確認

事前予約は最大6回・0.60 USD。6回の返却トークンによる概算は**0.000934 USD**。請求画面は未確認。前回までの予約12.65 USDと合わせて13.25 USDで、ユーザーの100 USD以下という試験許可の範囲内。

Responses API、`store=False`、自動再試行0、出力上限512。固定モデルは`gpt-4.1-mini-2025-04-14`と`gpt-4.1-2025-04-14`。Files APIへのアップロードはせず、画像・選択ページPDFをインライン送信した。PDFの成功はこの自作図についての結果で、論文PDF全体の精度や講義経路の対応を保証しない。

- 保存処理を変更した途中の単体試験で、保存する変数の名前の不一致を検出。修正後191件がpass。
- ライブラリ取得はサンドボックスのDNS制限で失敗。許可されたネットワーク経路で同じ固定版を取得し、導入を確認。
