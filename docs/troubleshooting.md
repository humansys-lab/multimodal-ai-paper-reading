# 困ったとき

接続・操作・記録の保存で困ったらTAに相談する。論文の内容や根拠の判断、予算・共通障害への対応は教員に確認する。受講者10名に対しTA1名が支援する。

| 状態 | 次に行うこと |
|---|---|
| 配布未準備／素材未採用 | 共通論文Paper2Agentは採用済み。表示された範囲・根拠・入力権利・実行経路の不足を教員に確認する |
| 認証失敗 | キーを共有画面や提出物に貼らず、配布元へ確認。講義用APIの利用期限は11/14 23:59（日本時間） |
| キー・接続情報を誤ってアップロード | 使用を止め、キー自体を書かずに教員へ連絡 |
| 予算制限・予算基盤停止 | 送信を止めて教員へ確認。基本利用を想定した1人10 USDの予算は確保済みだが、学生全体の合計使用量にも上限がある。自動再付与なし |
| レート制限 | 保存して教員の案内を待つ。連打しない |
| タイムアウト・通信失敗 | 費用・処理状況は不明。再送前に確認。失敗した問い合わせは成功した会話の履歴に入らない |
| 実行の停止ボタンを押した | 割込みを受け取れた場合は`interrupted`として保存できる。サーバで処理が続いた可能性と課金は不明。再送前に教員へ確認。ランタイム自体の強制終了では未保存の記録が失われるため、回答ごとに保存・ダウンロードする |
| 未対応設定 | 対応確認済み設定だけ使う。別パラメータへの自動置換なし |
| 実行済みの番号 | 二重送信を防いでいる。保存後、「次の実行番号」の`START_NEXT_RUN=True`を実行して質問欄へ戻る |
| カーネルの再起動 | 変数・会話の状態は消える。保存済みMarkdownで記録を確認し、準備セルからやり直して新規会話を始める |
| Colabのランタイム削除 | ランタイム内のファイルも消える。回答ごとにJSONL/Markdownを自分のPCへダウンロードしておく |
| ファイルが見つからない | ColabのFiles欄へ置いてからパスをコピー。PC側のパスはColabでは使えない |
| 質問・入力・設定が変わった | プレビューを再実行し、現在の内容を確認してから送信する |
| 値を書き換えたのに結果が変わらない | 変更したセルを実行してから次へ進む。01・02は質問のセル→プレビュー、03はトークン分割→埋込み→候補確率の順に実行する |
| PythonのSyntaxError | 引用符・カンマ・改行を確認する。1行は`'自分の説明'`、複数行は`"""`で前後を囲む。TAへ相談するときもキーは見せない |
| GPUを利用できない | 03はT4を明示して開始する。割当て不能なら教員へ伝える。別機種へ自動変更しない |

教員判断でGUIや保存済み記録に移る場合は「経路変更」「事前記録」と明記。人工応答を実測に見せない。予算上限や同時送信の保証はサーバ試験前にはできない。
