# HW1の論文を探す・出典を確認する

第1日の題材はPaper2Agentだけです。以下は授業後のHW1用。対象誌は**Nature／Scienceの本誌2誌**に確定しました（Q3 YES）。この2誌からP01以外の原著1報を探します。

## 探し方

1. 関心のある技術・現象・困りごとを一つ決め、出版社サイトでキーワード検索する。AIに候補を聞いても、表示された論文は自分で出版社ページを開く。
2. [Nature](https://www.nature.com/nature/)または[Science](https://www.science.org/journal/science)で、誌名、研究論文の区分、公開日、DOIを確認する。Natureドメインには他誌もあり、URLのドメインだけでは判定できない。
3. 出版社の掲載版本文を開き、Open Access表示・ライセンスを確認する。大学契約で読めることだけをOAと呼ばない。
4. Abstractと主要図を見て、関心のある主張を説明できそうかを考える。難しければ範囲を絞るか、別の候補を探す。教員に相談できる。

P01の参考文献も入口になりますが、そこには他誌や会議論文・プレプリントも含まれます。「P01に引用されている」だけでは対象条件を満たしません。誌名指定は出典の取り違えを減らすためで、媒体の価値や正しさを一律に判定するためではありません。

## 本人のYES/NO確認票

| 確認 | YESなら残す証拠 |
|---|---|
| 確定した対象誌リスト内か | 出版社に表示された正式な誌名 |
| 掲載済みの原著か | Article/Research Article/Report等の研究区分と掲載版URL。ニュース・解説・レビュー等は除外 |
| P01とは別の論文か | DOIを比較 |
| Open Accessの本文と条件を確認したか | OA表示、ライセンス、本文URL |
| 自分の関心と読む範囲を説明できるか | 理由、本文の節、図番号 |
| 授業のAIへ入力する条件を確認したか | 入力可否と確認者。不明なら送らず相談 |

不明はYESにしません。誌名・DOIの形式をコードで検査しても、科学的正しさや教員承認を自動認定したことにはなりません。

手元の`U_<local_id>`へ題名、著者、誌名、DOI、掲載URL、版、範囲、`publication_status: published`、`article_type: research`、`open_access: true`を記録します。出典条件の確認は`eligibility_review`、AI入力の確認は`input_review`に分け、各々`status`と`reviewer`を残します。本人の確認は教員採用・再配布許可・一般公開の同意ではありません。

E01等の候補はまだ登録していません。教員候補も同じ条件を確認します。記録を公開manifestへ登録する必要はありません。
