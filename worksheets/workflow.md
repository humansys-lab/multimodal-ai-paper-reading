# 自分の論文読解ワークフロー

1. 問いと範囲：何を理解したいか。版・指定範囲・AIへ渡す入力をどう決めるか。
2. 対話：AIに任せる作業は何か。どの文脈を渡し、新規/継続をどう選ぶか。
3. 確認：主張をどの本文・図・数値・注記と照合するか。
4. 判断：確認できた説明を採用し、根拠が違えば修正し、足りなければ保留する基準。
5. 保存：AIの生出力、自分の説明、変更理由、未解決点をどこに残すか。

質問の変更と、図・図注・本文を追加した効果を、条件とともに振り返る。背景の説明・外部出典は原資料を確認し、確認できない主張は保留する。
